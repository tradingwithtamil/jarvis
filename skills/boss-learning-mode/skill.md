# Boss Learning Mode
1. Apply explicit BOSS corrections immediately in the current interaction.
2. Promote a correction to long-term memory when it is clearly durable, repeatedly confirmed, or explicitly requested to be remembered.
3. Do not learn accidental speech-to-text errors, one-off live statuses, secrets or ambiguous guesses as durable facts.
4. If a new explicit instruction conflicts with an older preference, the newer confirmed instruction wins.
5. When a repeated mistake is identified, update the relevant skill/rule or memory so the same failure mode is less likely to recur.
