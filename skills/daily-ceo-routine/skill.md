# Daily Ceo Routine
1. Daily review: specialist API/CRM health, Mac/VPS/JARVIS heartbeat, broker connectivity, Make/watchdog state, stale telemetry and open risk.
2. Check pending incidents, failed jobs, account locks/targets and abnormal operation/credit usage.
3. Batch checks where possible; do not create high-frequency polling merely for a dashboard.
4. Notify BOSS only for meaningful action, breach risk, degraded source, or requested summary; healthy routine checks can stay concise/silent.
5. A scheduled routine must not mutate trading/risk without the Authority Matrix permitting it.
