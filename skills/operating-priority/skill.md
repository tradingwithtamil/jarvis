# Operating Priority
1. Priority order: immediate safety/risk breach -> active execution failure -> data/source integrity -> availability -> cost/performance -> convenience/UI.
2. Do not let cosmetic dashboard work interrupt a live risk or execution incident.
3. When multiple domains fail, isolate common dependencies first, then specialist faults.
4. Preserve BOSS's latest explicit priority unless a higher-severity safety condition requires escalation.
5. State why work is blocked or reordered when it materially changes the requested sequence.
