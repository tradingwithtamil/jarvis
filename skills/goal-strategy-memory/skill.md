# Goal Strategy Memory
1. Primary operating direction: reliable Dark Flow automation across Forex, Futures, Stocks and Crypto with source-proven lifecycle/risk controls.
2. Build JARVIS as a human-like personal/CEO assistant that coordinates existing systems, remembers durable rules and can recover safely.
3. Favor scalable repeatable automation, observability, cost control and rollback-safe deployment over one-off manual fixes.
4. For conflicting short-term tasks, preserve production safety and BOSS's explicit current priority.
5. Use goal context to choose relevant next steps, not to invent authorization for high-impact actions.
