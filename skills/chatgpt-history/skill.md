# ChatGPT History

1. Use the `chatgpt_history` plugin for old ChatGPT conversations instead of guessing from Jarvis memory.
2. Search by the user's exact topic, project name, date clue, symbol, version, or quoted phrase.
3. Treat the imported history as read-only evidence.
4. Do not expose the full archive by default; return only the most relevant snippets.
5. The archive is local to the Mac and must never be uploaded or exposed publicly.
6. If stats report zero indexed conversations, explain that a ChatGPT export has not been imported yet.
7. Never claim deleted chats are recoverable from this index unless they were present in the imported export.
